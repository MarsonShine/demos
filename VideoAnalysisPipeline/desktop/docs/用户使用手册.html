视频处理助手用户手册

本程序把一批课程视频处理为统一的 MOD 输出。您只需选择文件夹、运行预检并开始处理；程序不要求您安装 Python、FFmpeg 或执行命令。

安装

  1. 下载管理员或发布页提供的 VideoAnalysisDesktop-Setup-x64-版本号.exe。
  2. 双击安装包，按向导选择“安装”。Windows 要求权限确认时选择“是”。
  3. 从桌面或开始菜单打开 VideoAnalysisDesktop。

安装包已包含处理运行时、FFmpeg 和模型。请不要从安装目录删除文件。

首次使用：由管理员配置

管理员点击主界面的 Admin Settings，按组织提供的信息填写 Azure OpenAI Endpoint、API Key 和 Deployment 名称，然后保存。普通操作人员不需要、也不应复制或查看 API Key。

准备输入文件

选择一个输入根目录。每个需要处理的课程子文件夹必须包含：

  • 1 个 MP4 视频；
  • 1 个 SRT 字幕；
  • 可选的 1 个 MP3 背景音频。

MP4 和 SRT 必须在同一个子文件夹内。不要在一个子文件夹放两段视频或两份字幕；输出目录也不能放在输入目录里面。

处理一批文件

  1. 点击 选择输入目录，选择准备好的输入根目录。
  2. 点击 选择输出目录，选择一个新的、空的文件夹。建议每次任务都新建输出文件夹。
  3. 点击 运行预检。预检会检查文件结构和项目数量，不会处理视频。
  4. 预检显示通过后，点击 开始处理。
  5. 等待进度完成。处理期间请不要关闭程序、移动输入文件或删除输出文件。

查看结果

任务成功后点击 打开输出目录。每个项目会生成：

  • dubbing\1\01.jpg：封面图
  • dubbing\1\01.mp4：处理后的视频
  • dubbing\1\02.mp4：静音视频
  • dubbing\1\03.mp3：音频
  • movie_dubbing.xlsx：汇总表

多个项目会使用 dubbing\1、dubbing\2 等连续编号。

取消或继续失败任务

  • 需要停止时点击 取消，并等待界面显示任务已取消。
  • 任务失败后，不要更改输入、输出或已经生成的文件。重新打开程序后选择 继续失败任务，程序会检查原始文件与处理参数后继续。

常见提示

提示处理方法
预检失败检查每个课程子文件夹是否恰好有 1 个 MP4 和 1 个 SRT。
输出目录必须为空新建一个空文件夹作为输出目录。
输入/输出目录重叠选择与输入目录完全分开的输出位置。
管理员凭据未配置联系管理员在 Admin Settings 中完成配置。
内置处理引擎或 FFmpeg 不可用重新运行安装包；不要手动复制或删除安装目录中的文件。
任务失败保留输出目录和日志，先使用“继续失败任务”；仍失败时把日志交给管理员。

更新、卸载与数据

更新时直接运行新版本安装包。卸载可从 Windows“已安装的应用”或开始菜单的卸载项执行。输入与输出文件保留在您选择的磁盘目录；转写和翻译会按管理员配置连接组织的 Azure 服务，请遵守组织的数据使用规范。
