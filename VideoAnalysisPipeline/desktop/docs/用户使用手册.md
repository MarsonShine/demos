# 视频处理助手用户手册

## 这是什么

视频处理助手会把一批符合规则的课程视频处理为统一的 MOD 输出。您只需要选择
输入文件夹和一个空的输出文件夹，在程序中查看进度；视频编码、音频处理和模型都
已经包含在安装包内。

## 安装

1. 从管理员或发布页面下载 `VideoAnalysisDesktop-Setup-x64-版本号.exe`。
2. 双击安装包，按安装向导选择“安装”。Windows 出现权限确认时选择“是”。
3. 安装完成后，从桌面或开始菜单打开“VideoAnalysisDesktop”。

首次安装不需要安装 Python、FFmpeg、浏览器插件，也不需要执行任何命令。

## 第一次使用：管理员配置

首次使用前，需要由管理员点击主界面的 **Admin Settings**，填写组织提供的：

- Azure OpenAI Endpoint
- API Key
- Deployment 名称

保存后关闭设置窗口。普通操作人员不需要、也不应查看或复制 API Key。

## 准备输入文件

选择一个“输入根目录”。输入根目录下可以有多个课程子文件夹；每个要处理的子文件夹
必须包含：

- 1 个 MP4 视频文件；
- 1 个 SRT 字幕文件；
- 可选的 1 个 MP3 背景音频文件。

MP4 和 SRT 必须在同一个子文件夹内，文件名可以不同。不要把输出目录放入输入目录，
也不要在一个子文件夹放两段视频或两份字幕。

## 处理一批文件

1. 打开程序，点击 **选择输入目录**，选择准备好的输入根目录。
2. 点击 **选择输出目录**，选择一个新的、空的文件夹。建议每次任务新建一个输出文件夹。
3. 点击 **运行预检**。程序会检查目录结构、统计项目数，但不会处理视频。
4. 预检显示“通过”后，点击 **开始处理**。
5. 等待进度显示完成。可查看当前项目、阶段、完成数量和日志。

处理过程中请勿关闭程序、移动输入视频或删除输出文件。处理耗时取决于视频长度、数量、
电脑性能和网络状况。

## 查看结果

任务成功后点击 **打开输出目录**。MOD 输出包含：

- `dubbing\1\01.jpg`：封面图；
- `dubbing\1\01.mp4`：处理后的视频；
- `dubbing\1\02.mp4`：静音视频；
- `dubbing\1\03.mp3`：音频；
- `movie_dubbing.xlsx`：汇总表。

多个输入项目会使用 `dubbing\1`、`dubbing\2` 等连续编号。

## 取消与继续失败任务

- 需要停止时点击 **取消**，并等待界面提示任务已取消。
- 如果网络、服务或电脑问题导致失败，不要更改输入目录、输出目录或已生成的文件。
  重新打开程序后，选择 **继续失败任务**。程序会重新检查输入快照和固定处理参数，
  确认一致后继续未完成部分。

不要把失败任务的输出目录用于新的任务；新任务必须使用空输出目录。

## 常见提示

| 提示 | 处理方法 |
| --- | --- |
| 预检失败 | 检查每个课程子文件夹是否恰好有 1 个 MP4 和 1 个 SRT。 |
| 输出目录必须为空 | 新建一个空文件夹作为输出目录。 |
| 输入/输出目录重叠 | 选择与输入目录完全分开的输出位置。 |
| 管理员凭据未配置 | 联系管理员在 **Admin Settings** 中完成配置。 |
| 内置处理引擎或 FFmpeg 不可用 | 重新运行安装包；不要从安装目录删除文件。 |
| 任务失败 | 保留输出目录和日志，使用“继续失败任务”；仍失败时把任务日志交给管理员。 |

## 更新和卸载

更新时下载新版本安装包并直接运行。安装向导会替换程序文件，但会保留已生成的输出、
任务记录和模型缓存。卸载可从 Windows“已安装的应用”或开始菜单的卸载项执行。

## 数据与网络

输入视频和输出文件保留在您选择的磁盘目录。转写和翻译功能会按管理员配置连接组织的
Azure 服务；请遵守组织的数据使用规范。不要把 API Key 写入文件名、字幕或任务备注。
